# Code of Conduct

## The short version

Be decent. Argue about statistics, not about people.

## Expected

- Critique the backtest, the check, the code — not the person who wrote it.
- Assume the other person is trying to be correct, not trying to win.
- Accept "no" on scope. Maintainers keep this tool small on purpose; a declined
  feature is not a personal judgment.
- Say "I don't know" freely. This project is about not overstating confidence.

## Not accepted

- Harassment, insults, or personal attacks, public or private.
- Discriminatory language or imagery of any kind.
- Publishing someone's private information without permission.
- Deliberately derailing issues or PRs, or repeatedly reopening settled scope
  decisions.

## Scope

Applies to issues, pull requests, discussions, commit messages, and any public
space where someone is representing this project.

## Enforcement

Report conduct problems by opening a
[private security advisory](https://github.com/kire21b/falsify/security/advisories/new)
(it is private to the maintainers, and works for conduct reports too), or by
contacting the maintainer through their GitHub profile.

Reports are handled privately. Consequences range from a warning to a permanent
ban from the repository, at the maintainers' discretion. Maintainers who don't
follow this document are subject to the same consequences.
